# Gyaraplus 11+ English — Explanation Sub-Levels (`9 → 1`) (`gyaraplus/english/levels.md`)

> **Purpose:** Defines how 11+ English steps scale from **`Level 9`** (expected 11+ comprehension/writing mastery) down to **`Level 1`** (concrete picture/word-level intuition).

| Sub-Level | 11+ English Pedagogical Role | Carbon Board Representation |
| :---: | :--- | :--- |
| **`9`** | **Expected 11+ P.E.E. / Exam Deduction** | Clean quotation highlight + concise Point → Evidence → Effect card (or model paragraph). |
| **`8`** | **Guided Evidence Link + Exam Cue** | Explicit cross-pane pointer from command word in prompt to exact 3–5 word phrase in passage. |
| **`7`** | **Word-Choice & Technique Zoom** | Pinpoint `\htmlId` callouts on individual verbs/adjectives/imagery explaining literal vs implied meaning. |
| **`6`** | **Clause-by-Clause Plain-English Unpacking** | Side-by-side `smartTable` translating tricky 19th/20th-century clauses into plain Year-6 English. |
| **`5`** | **Distractor / Exam Trap Contrast (`✗` vs `✓`)** | Contrasts the tempting misreading (or copying verbatim in an own-words question `✗`) against accurate inference (`✓`). |
| **`4`** | **Sentence Skeleton / Fill-in Frame** | Structured sentence starters / P.E.E. scaffold boxes showing how the pieces slot together. |
| **`3`** | **Visual Story / Character Map** | Simple visual relationship map, timeline strip, or mood thermometer diagram on Carbon. |
| **`2`** | **Everyday Real-Life Situation Analogy** | Relates the character's feeling or metaphor to a familiar everyday playground/home situation. |
| **`1`** | **Single-Word & Concrete Picture Intuition** | Concrete illustrated visual / single-word emotion & object association. |
