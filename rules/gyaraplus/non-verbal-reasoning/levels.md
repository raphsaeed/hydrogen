# Gyaraplus 11+ Non-Verbal Reasoning — Explanation Sub-Levels (`9 → 1`) (`gyaraplus/non-verbal-reasoning/levels.md`)

| Sub-Level | 11+ NVR Pedagogical Role | Carbon Board Representation |
| :---: | :--- | :--- |
| **`9`** | **Fast 2-Rule SPANS Elimination** | Spots the 2 decisive SPANS rules, crosses out eliminated options, confirms winner. |
| **`8`** | **Annotated Feature Tags + Check Table** | Adds concise rule arrows between sequence frames + compact verification table. |
| **`7`** | **Isolated Layer / Feature Spotlight** | Highlights only the active sub-shape (dimming distractors) to trace one rule cleanly. |
| **`6`** | **Frame-by-Frame Transformation Trace** | Draws intermediate rotation/movement steps ($0^{\circ} \to 45^{\circ} \to 90^{\circ}$) or reflection mirror lines. |
| **`5`** | **Visual Trap Contrast (`✗` vs `✓`)** | Side-by-side comparison of the surviving distractor vs winner (or `netFold` `"highlightCollisions": true`!). |
| **`4`** | **Deconstructed Shape Layers** | Separates outer frame, inner shape, and shading into 3 separate clean mini-strips. |
| **`3`** | **Interactive 3D Fold / Live Rotation Sweep** | Uses Carbon `netFold` (`@fold` slider `0 → 1`), `cubeAssembly` orbit, or live rotation sweep. |
| **`2`** | **Clock-Face / Mirror Grid Guide** | Overlays a familiar clock face ($12 \to 3$ o'clock $= 90^{\circ}$) or grid squares to count movement. |
| **`1`** | **Single-Shape Concrete Counting / Matching** | Counts sides/dots `1, 2, 3...` or matches a single shape's color/direction one piece at a time. |
