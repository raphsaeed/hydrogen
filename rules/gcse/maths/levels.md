# GCSE Maths — Explanation Sub-Levels (`9 → 1`) (`gcse/maths/levels.md`)

| Sub-Level | GCSE Maths Pedagogical Role | Carbon Representation |
| :---: | :--- | :--- |
| **`9`** | **Expected Full-Marks GCSE Exam Working** | Clean GCSE `M1/A1` derivation + required graph/geometry sketch + `Check`. |
| **`8`** | **Fast Annotated Exam Working + Tip Badge** | Adds inverse flow tags, `[Non-calc]` / `[Marks]` exam-craft tip card & reverse check. |
| **`7`** | **Token-Pointer Working + Candidate Scratchpad** | `\htmlId` pointers on key algebraic moves + `rough-margin` factor/candidate scratchpad. |
| **`6`** | **Unpacked Micro-Steps / Deterministic Method Pivot** | Zero hidden leaps (`edit.rub`, `fracCancel`, or pivoting inspection $\to$ deterministic `ac` split). |
| **`5`** | **GCSE Classic Mistake Contrast (`✗` vs `✓`)** | Side-by-side Red `✗` (sign error, premature rounding, expanding `"Hence"` from scratch) vs Green `✓`. |
| **`4`** | **Expanded Prime/Letter Strips & Easy-Numbers Mirror** | Deconstructs powers (`8x²y = 2·4·x·x·y`) or mirrors algebra beside simple numbers. |
| **`3`** | **Spatial Model (`areaGrid` `2×2` Box / `barModel` / `functionMachine`)** | 2D multiplication/factorising grid, bar model, balance scale, or test-points shift graph. |
| **`2`** | **Number-Line Hop Arcs & Visual Fraction Bars** | Directed number line (for negative arithmetic) or `fractionBar` visual slices. |
| **`1`** | **Concrete Grouping & Real-World Intuition** | Concrete `counters` / everyday object quantities grounding the underlying arithmetic. |
