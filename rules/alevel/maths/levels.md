# A-Level Maths — Explanation Sub-Levels (`9 → 1`) (`alevel/maths/levels.md`)

| Sub-Level | A-Level Maths Pedagogical Role | Carbon Representation |
| :---: | :--- | :--- |
| **`9`** | **Expected Concise A-Level Exam Derivation** | Streamlined exact derivation + clean `coordinatePlane` / vector / mechanics sketch. |
| **`8`** | **Guided A-Level Step + Differentiation/Domain Check** | Adds rule tags (chain/product/IBP), domain/pole checks, and 1-line reverse check. |
| **`7`** | **Token-Annotated Algebra/Calculus + Substitution Box** | Pinpoint `\htmlId` pointers on inner functions, integration limits, or `u`-substitutions. |
| **`6`** | **Zero-Leap Algebraic & GCSE-Bridge Unpacking** | Expands index laws, fractional powers ($1/\sqrt{x} = x^{-1/2}$), and sign cancellations line by line. |
| **`5`** | **Classic A-Level Trap Contrast (`✗` vs `✓`)** | Contrasts missing $+c$, wrong radian/degree mode, or integrating across a sign change (`✗` vs `✓`). |
| **`4`** | **Concrete Function / Numerical Pattern Mirror** | Mirrors abstract calculus/log rule beside a concrete numerical/polynomial example. |
| **`3`** | **Visual Geometric / Riemann / Vector Stage** | Carbon `coordinatePlane` (`tangentAt`, `riemannSum`, `signedIntegral`) or 3D `solidOfRevolution`. |
| **`2`** | **Interactive Parameter Scrub (`@param` Slider)** | Live tangent-gradient or area accumulation sweep as student scrubs `$x_0$`. |
| **`1`** | **Foundational Rate-of-Change / Area Intuition** | Everyday slope (steepness of a hill) or counting grid squares under a curve. |
