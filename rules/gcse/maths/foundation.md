# GCSE Maths — Foundation Tier Overlay (`gcse/maths/foundation.md`)

- **Target Range:** Grades `1–5`.
- **Method Preference at `Level 9`:** Favor clear structured multi-line steps, explicit unit conversions, ratio tables/`barModel` where helpful, and factorable quadratics ($x^2 + bx + c = 0$ with $a = 1$); avoid Higher-only topics (surd rationalization, completing the square, algebraic fractions, sine/cosine rules, histograms with unequal widths, vectors proof).
