# GCSE (Ages 14–16) — Product-Wide Common Rules (`gcse/common.md`)

> **Scope:** Shared across all **UK GCSE** vaults (`gcse-maths.raphs`, `gcse-physics.raphs`, etc.). Strictly isolated from 11+ and A-Level rules.

- **Tiers & Target Grades:** Support **Foundation Tier (Grades `1–5`)** and **Higher Tier (Grades `4–9`)**, recording `tier` (`"foundation"` | `"higher"`) on papers and questions.
- **Exam Command Words & Mark Discipline:** Respect GCSE command words (*"State"*, *"Work out"*, *"Show that..."* — must display every intermediate line, *"Hence..."* — must use prior part's result) and GCSE mark allocation (`M1` method, `A1` accuracy, `B1` independent, `C1` conversion/communication).
- **Answer Precision:** Exact fractions/surds/$\pi$ multiples on Non-Calculator papers (or when `"exact"` is asked); **`3 significant figures` (`3 s.f.`)** default on Calculator papers unless specified otherwise, with zero premature intermediate rounding (`exportedExact` chained via Theta).
