# Hydrogen

**Hydrogen** is the pure-Rust curriculum compiler toolkit, `Level 9 → Level 1` visual solution verifier, product authoring ledger (`ledger.json` + `status.html`), and encrypted `.raphs` course vault manager (`memory.raphs` Schema `2.3.0` Layer `L7`), verified with **Theta** (`theta_calc`) and pre-compiled for **Carbon** (`Carbon Protocol v0.1`) and **SIGMA**.
